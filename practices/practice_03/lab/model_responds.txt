2. Вызвать команду для запуска тестов: `make test`

Теперь, чтобы запустить CI-систему на конкретном проекте, нужно будет настроить автоматическую проверку на CI-системе. Например, в GitHub Actions это может выглядеть следующим образом:

```yaml
# .github/workflows/test.yml
name: Test

on:
  push:
    branches: [ master ]

jobs:
  test_job:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Setup Python
        uses: actions/setup-python@v2
        with:
          python-version: '3.10'
      - name: Install dependencies
        run: pip install -r requirements.txt
      - name: Run tests
        run: make test
```

Таким образом, каждое изменение в ветке `master` будет автоматически запускать команду `make test` с установленными зависимостями.

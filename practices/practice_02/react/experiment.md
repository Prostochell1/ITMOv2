# ReAct

- Цель:
  - Подготовить проверяемые правки practices/practice_01/project_management.md: даты, роли, зависимости, проверки со ссылками.
- Доступные входы:
  - practices/practice_01/project_management.md, tests_*.md, analysis.md, adr.md, prompts.md (P1-02), CASE.md, TRAINING_PR.diff.
- Разрешённые действия:
  - Read(file, section|hint)
  - Validate(rule|test_ref)
  - ProposeDelta(target_section, text)
- Запрещённые действия:
  - Внешние источники; изменения файлов кроме project_management.md.
- Максимальное число шагов:
  - 6
- Условие остановки и вопроса человеку:
  - Остановиться, если не хватает согласованных дат/ролей или конфликтуют зависимости.

## Запрос

Выполни пошагово ReAct-план (таблица шагов), затем предложи компактный список ProposeDelta для project_management.md.

|---|---|---|---|
| 1 | Read(project_management.md, "Инкременты и ответственность") | Даты/роли/зависимости нуждаются в конкретизации | Продолжить |
| 2 | Validate(tests_e2e.md — сценарии; CASE API-1) | Есть сценарии на >20К и отсутствие diff | Продолжить |
